# Archive - Tệp .md gốc

Thư mục này lưu **bản gốc .md** đã chuyển vào archive (12 file), giữ nguyên để tham chiếu.
Bản HTML để xem/cập nhật nằm tại `P1/Output/all-docs.html` (gộp) và `archive/html/` (lẻ).

- Chỉ `README.md` gốc ở repo root được giữ lại ngoài archive.
- Không xóa — chỉ di chuyển để repo gọn.
