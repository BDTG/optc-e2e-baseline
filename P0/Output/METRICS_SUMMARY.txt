================================================================
                   ACCURACY CAVEAT
================================================================
ORTHRUS reports Accuracy = 99.96%. This number is NOT representative
and should NOT be cited as a sign of good detection:

- Positive class rate is only 114 / ~927,476 nodes = 0.012%.
- A trivial "predict all benign" baseline would score 99.988%,
  HIGHER than ORTHRUS.
- Accuracy is dominated by True Negatives (correctly flagged benign
  nodes), which are the vast majority.
- The meaningful metrics under this extreme imbalance are:
    * ROC-AUC = 0.9409  (ranking power)
    * Recall   = 0.0790  (caught 9 / 114 malicious)
    * FP        = 3,406   (false alarms)
  Use AUC / Recall / Precision@k / F1 for reporting, NOT Accuracy.
